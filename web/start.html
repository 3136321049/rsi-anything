01 / INSTALL

准备项目与个人助手

建议 Python 3.11，安装 Git，并在运行这台电脑上登录个人 Codex 或其他受支持的编程助手。

获取源码 · macOS / Linux / WSL
git clone --branch rebuild https://github.com/3136321049/rsi-anything.git
cd rsi-anything
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
rsi agents

Windows 可使用 Ubuntu 子系统。原生 PowerShell 的环境激活命令为 .venv\Scripts\Activate.ps1。不同领域的附加依赖见模板说明。

03 / KEEP & SHARE
把结果带走
作品和完整记录保存在任务目录中。生成报告查看过程，再导出可分享的结果文件。
在任务目录中执行
rsi status
rsi report
rsi export --to ../my-rsi-result
中断后可以按原配置恢复。改变目标、输入或评价方式时，开始一份新的运行记录。
