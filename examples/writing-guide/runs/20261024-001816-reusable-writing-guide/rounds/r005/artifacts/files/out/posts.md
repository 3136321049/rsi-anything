# 简报 coffee

产品：巷口咖啡晨间自取

目标读者：早上赶地铁的上班族

给定事实：工作日07:30至10:00提供自取；美式16元，拿铁22元；手机点单后可预约15分钟内的取餐时段；到店后在标有预约时段的架子上取杯；门店距离地铁口步行3分钟；自带杯减2元

给定行动入口：在门店小程序选择晨间自取

## 生成稿

赶地铁的早晨，咖啡怎么取？

早上要带杯咖啡再去坐地铁，可以先按取餐时段安排到店。巷口咖啡晨间自取支持手机点单，能预约15分钟内的取餐时段；到店后，在标有预约时段的架子上取杯。

这项自取服务只在工作日07:30至10:00提供。门店距离地铁口步行3分钟，选取餐时段时，记得给取杯后走到地铁口留出这段时间。

想好喝什么，也能提前算清花费：美式16元，拿铁22元，自带杯减2元。如果打算自带杯，可以先确认杯子如何交给门店、是否影响预约自取安排。

在门店小程序选择“晨间自取”，下单时选好取餐时段，到店后按架子上的时段标识找杯。

# 简报 repair

产品：周末自行车检查台

目标读者：车放了一个冬天、准备恢复通勤的人

给定事实：周六10:00至16:00开放；基础检查29元，约20分钟；包含胎压、刹车、链条和车灯检查；发现需换配件时先报价，经车主同意再换；不含配件价格；可预约整点或半点时段

给定行动入口：在店铺页面预约检查时段

## 生成稿

自行车放了一冬，通勤前查什么？

准备把放了一个冬天的自行车重新骑去通勤，可以先查查胎压、刹车、链条和车灯。「周末自行车检查台」的基础检查包含这四项，29元一次，约20分钟。

担心检查时发现要换零件，费用超出预期？如果发现需要更换配件，会先报价，经你同意后再换。29元是基础检查费，不含配件价格；检查和换件的费用要分开看，是否更换由你确认。

检查台周六10:00至16:00开放，可预约整点或半点时段。如果准备周六把车带去检查，可以在店铺页面选择对应时段预约，给这次检查留出约20分钟。

# 简报 pottery

产品：泥点陶艺入门课

目标读者：想尝试手作但没有经验的成年人

给定事实：每周日下午14:00开始，课程90分钟；每人128元；最多8人一班；包含材料、工具和一次烧制；作品需烧制后约两周领取；围裙由工作室提供，建议穿方便活动的衣服

给定行动入口：在工作室公众号回复入门课查看名额

## 生成稿

第一次做陶艺，作品要等两周领取

想试试亲手做一件陶艺作品，先留意：作品不能在上完课当天带走。泥点陶艺入门课包含一次烧制，作品需烧制后约两周领取。如果想把成品带回家，除了上课当天，还要留出之后领取的安排。

课程每周日下午14:00开始，一次90分钟，最多8人一班，面向想尝试手作、还没有经验的成年人。

每人128元，费用包含材料、工具和一次烧制，不用自己准备材料和工具。工作室也提供围裙，去上课建议穿方便活动的衣服。

想参加的话，可以在工作室公众号回复“入门课”，查看名额。
