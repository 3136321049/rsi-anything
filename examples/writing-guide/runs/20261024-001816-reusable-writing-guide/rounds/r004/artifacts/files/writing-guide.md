# 产品笔记写作手册

围绕读者的一次实际决定来写。动笔前先从简报找出：读者正要做什么，哪件具体的麻烦或顾虑最影响决定，哪些已知事实能帮助他判断。不要只把人群标签换进同一套句子，也不要替读者编造经历或情绪。

开头把读者想做的事与一条能消除犹豫的事实连起来，让人马上知道这款产品为什么值得继续看。先回答与尝试或使用本身有关的问题；时间、领取、预约等流程条件，只有直接决定读者能否使用时才放在最前面，不因它们具体、容易写就优先。直接说清产品提供什么、读者需要做什么，用事实作答，少用“先弄清楚”“安排好时间”“考虑进去”等提醒代替答案。可以陈述，也可以提出紧接着就能回答的问题，不固定使用疑问句或“可以了解一下”。标题也围绕这个具体需要，不只写产品名或泛泛的推荐。

正文先解决最影响这次决定的一个顾虑，再补足参与或使用所需的信息，不固定按时间、费用、预约的顺序展开。判断重点时，问自己：读者即使知道产品是什么，仍会因哪件具体的事犹豫？简报中哪条事实能直接回答？让这组顾虑与事实占据开头和正文的主要篇幅，其余条件放在相关处交代。把特点放回它所解决的问题里说清楚，不逐项堆卖点；不要把“没经验”“很忙”等人群描述本身当作顾虑的答案。涉及费用、准备、时间、预约等条件时，只选与本次决定有关且简报给出的内容；重要限制紧跟相关信息，不藏在结尾。读者可能关心但简报没说的事，不自行补全，也不当成已获保证。

结尾顺着尚待完成的一步，说明读者可通过简报提供的入口做什么。入口和动作要对应；没有提供的预约方式、私信回复或联系方式不要添加。需要确认的信息可以提示先确认，不能把未知条件写成确定事实。避免开头和结尾重复邀请“了解详情”，不为凑完整而加一句泛泛的号召。

语气友好，使用短段落。成稿只对读者说话，不出现“简报提到”“资料未说明”等写作背景，也不向读者解释自己的信息排序。读一遍开头、段落衔接和结尾：若换个产品名仍能原样使用，就用本篇最相关的事实重写，删掉没有新增信息的提醒和条件式邀请。表达差异来自不同顾虑和事实，不靠轮换同义句或添加口头禅。内容只能来自简报，不添加没有给出的价格、用户评价和效果承诺。
标题不超过20字，正文控制在180到400个中文字符左右。
