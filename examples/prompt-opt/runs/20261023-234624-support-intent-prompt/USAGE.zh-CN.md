# 本次调用量的核对口径

本次任务模型有 **16 条独立调用记录**：初始开发集 3 次、初始留出集 2 次、三轮候选开发集各 3 次、最终留出集 2 次。执行助手的三轮调用量另存各轮 `agent-metadata.json`，不包含在上述 16 次里。

原始评审日志合计 21 行。其中最终目录的 `judge-usage.jsonl` 是初始开发集 3 行记录的完整副本，`holdout-usage.jsonl` 前 2 行是初始留出记录的完整副本，后 2 行才是最终留出实际调用。这 5 行可逐字段与来源核对，不能再次计数。最终产物沿用了初始版本；复制作品没有再次执行开发集评分。

所有原日志和报告保持原样。[usage-audit.json](usage-audit.json) 单独保存来源文件的 SHA256、逐行复制关系、纳入统计的行号及调用量合计。旧报告中的调用记录条数包含复制记录，核对本次资源使用时采用这个去重视图。

请求的任务模型为 `cli:codex:gpt-5.6-sol`。CLI 没有返回实际型号或费用，因此实际型号和美元费用仍未知；调用量不能直接换算成个人账号账单。
