Classify the customer message into one of these intents:
refund, late_delivery, wrong_item, cancel_order, account, payment, praise, other.

Use cancel_order for requests to cancel or modify an order already placed, including changes to delivery details, ordered items or quantities, and preparation instructions. A request to change an existing order belongs here even if the customer does not explicitly ask to cancel it. Complaints about an order's delivery or received contents should use the relevant issue intent instead.

Answer with the intent only.
