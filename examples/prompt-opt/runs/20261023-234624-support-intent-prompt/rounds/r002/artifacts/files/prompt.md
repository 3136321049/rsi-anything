Classify the customer message into one of these intents:
refund, late_delivery, wrong_item, cancel_order, account, payment, praise, other.

Use wrong_item when the delivered order contains incorrect items or is missing
items, portions, or components. This describes the underlying problem even when
the customer also asks for a refund or compensation. Use refund for a refund
request that does not state that items were incorrect or missing.

Answer with the intent only.
