# Adapters

These directories are plugs, not vendored upstream trees. Each `ATTRIBUTION.yaml` records who the idea came from, what we used, and where it shows up in this repo. Copying upstream code would require a pinned revision, the SPDX license, and the notices the upstream project asks for. Until that pin exists, `license` stays `verify-upstream` and `relationship` stays `inspiration`.

| Bridge | Upstream idea | Where the ratchet uses it |
|---|---|---|
| `autoresearch-bridge` | Fixed-budget modify, measure, keep-or-reset | Finance demo loop and any `GOAL.md` ratchet |
| `ralph-wiggum-bridge` | Do not stop while tests and review are red | Engineering handoff; worktree locks in the engine |
| `textgrad-dspy-bridge` | Turn a critique into a local edit | ML starter and rubric suggestions |
| `deep-research-bridge` | Multi-source research with citations | Finance and humanities tracks |
| `ai-scientist-bridge` | Search, write, and review a study end to end | ML and research tracks, without auto-editing the judge |
