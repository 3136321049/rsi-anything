## 当前边界与保存方式

开发主线为 `rebuild`。源码、共享文档和已导出案例按明确审查清单同步，另一台电脑按[跨电脑协作](COLLABORATION.zh-CN.md)接手。新实验在独立目录运行，原始账本、失败候选和历史部分运行保留；本机缓存、账号和未导出的运行分支不上传。上传检查与复核范围见 `release/github-sync-audit.json`，最近一次完整回归 115 项通过。

完整测试 114 项通过。已有展示及案例浏览器检查记录保留；本地展示的再次浏览器访问被权限检查拒绝，因此最终数据更新只做文件、逻辑和媒体检查，没有绕过访问限制，也不声称新一轮浏览器视觉检查通过。

D07 的免费服务在受理请求后返回不透明错误，有限诊断仍失败，无法确定是额度、GPU 还是服务内部原因。原账本保持原样，派生展示把缺少作品的轮次标为质量未知。D15 没有个人 GPU，只交付可运行模板、公开来源、无设备检查及补跑入口。

全部来源限公开资料与独立实现。个人模型调用隔离用户配置；依赖使用隔离 Python 环境。安装包不包含账号配置、实验缓存、内部资料或本机用户名路径。当前范围内的敏感文本模式扫描无匹配。
