# 推理加速与算子优化：公开资料与 Demo 计划

日期：2026-10-23。本文为 D15 的设计与选型资料，尚未实现模板或运行 GPU 实验。资料来源限定为下列公开项目、官方文档和独立设计。

## 1. 产品场景

让 AI 优化神经网络的一段计算：先测哪些计算耗时，再修改一个 GPU 算子实现，检查计算结果是否在约定误差内，测量速度，保留有效改动，继续尝试。

首版展示两层结果：一个独立算子的多轮优化，以及把最终算子替换进小型推理模块后的整体耗时。两层指标分别展示，算子速度变化不能直接作为整个模型的加速倍数。

这与现有模糊搜索提速模板不同：这里涉及 GPU 编译、并行划分、内存访问、计算融合和数值误差。保留现有 RSI 主循环，新增领域模板与评价适配。

## 3. 首版范围与实现顺序

### A. 环境与基线

先检查可用且已授权的个人计算资源、设备型号、驱动及 PyTorch / 编译工具版本。只有 CPU 或不兼容设备时，先完成模板、配置和无 GPU 错误提示，将 GPU 实测列为待完成；不得把模拟计时或 CPU 结果当作 GPU 加速。

不默认调用企业计算环境。需要租用 GPU 或新增付费服务时，先说明规格、预计用途和预算，再获得用户决定。

先选一个能在该环境运行的公开小任务。优先试行融合 Softmax；若当前硬件或基线已无明显可改空间，按实测选择归一化或小型融合计算，不承诺固定倍数。

基线区分清楚：原始组合实现、框架内置实现、初始候选。对外展示说明比较对象。初始候选应正常工作，由后续模型尝试带来变化，不预写一串“优化版本”。

### B. 单算子多轮优化

建议模板名为 `kernel-speed`，以下是拟新增文件而非现有实现：

- `rsi.yaml`：目标、可改路径、评审命令、轮数与超时。
- `candidate.py`：助手可修改的 GPU 算子及必要启动参数。
- `judge/reference.py`：固定的参考计算与接口约定。
- `judge/check.py`：结果校验、预热、计时和结构化反馈。
- `judge/cases.json`：自行设计或来自许可明确的公开题目的输入形状、数据类型、随机种子和容差。
- `judge/module.py`：用于集成对照的小型推理模块。
- `README.md`：设备要求、安装、运行和结果查看方法。

每轮让助手依据编译错误、数值错误或性能反馈修改候选。使用现有命令式评审返回分数、检查结果和反馈；继续使用现有 Git 分支、逐轮记录和报告机制。

可探索的公开常见方向包括减少中间张量读写、合并相邻计算、调整并行划分、分块与启动参数。每轮记录修改假设，避免只盲扫参数而无法解释变化。

### C. 小型推理模块集成

使用自行编写的小型神经网络计算模块，或许可明确的公开样例，将初始与最终算子各自接入相同调用路径。记录模块输出误差、整体耗时及算子在其中的耗时。

保持模型结构、输入、精度和运行配置一致。初版无需接入生产服务、多机通信或大模型权重；小模块可以使用随机初始化参数和合成输入，但要说明这不是语言生成任务。

如果最终算子没有给模块带来收益，保存结果，分析该计算所占比例与调用开销，选择有意义的下一项尝试。只有模块实测改善时才描述该模块的推理加速。

## 4. Demo 级评测要求

1. 先检查形状、数据类型、输出误差，以及少量常见和边界输入；容差在实验前配置，不能让候选为过关修改。
2. 先完成编译和预热，再测稳态执行耗时；冷启动与编译成本可另列。
3. 使用适合设备的同步或计时方式，重复测量并报告中位数，避免只记录一次最快值。
4. 对照使用相同设备、输入和计时范围；外部工具或候选挂住时能超时退出。
5. 单算子、模块整体、端到端服务分别命名；本 Demo 未测的层级不填数。
6. 尝试约 5–8 轮，保存候选、错误、速度、接受或拒绝原因；是否有提升由实际结果决定。

公开评测方法参考 [KernelBench](https://github.com/ScalingIntelligence/KernelBench) 的正确性与性能分开检查，以及 [Triton Softmax 教程](https://triton-lang.org/main/getting-started/tutorials/02-fused-softmax.html) 的融合计算和基准示例。上述具体实施安排是本项目建议。

## 5. 展示与验收

展示内容包括：原始计算做什么、每轮改动摘要、当前最好算子耗时曲线、代表性代码差异、数值误差、不同输入规模结果、小模块整体耗时，以及设备与软件版本。

首版验收为：一个公开或独立构造的任务真实跑完多轮；初始与最终实现、逐轮记录和基本正确性结果齐全；完成一次小模块替换对照；能够按文档重跑。没有 GPU 实测时保留“待实测”，不以模板完成替代验收。
