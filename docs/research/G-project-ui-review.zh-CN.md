## 源码决定的产品边界

`scripts/build_showcase.py` 根据目录和原始运行生成静态页；`src/rsi_anything/report.py` 生成单次报告。当前集合 HTML 约 3.21 MB，包含较多内嵌文字和 HTML，媒体通过文件链接读取。任务创建、执行、恢复和导出在命令行完成，网页运行服务尚未实现。

现有轮次账本已经记录修改假设、决定、分数、最好结果、检查、反馈、改动路径、耗时、费用与作品位置，足以供不同领域页面复用。状态文件记录当前阶段；这些记录可以支持后续进度显示。排队、网页鉴权、重复提交控制和可靠的网页停止操作仍需新增。

`code-speed` 的评价先核对搜索结果，再测耗时；每次评价生成随机输入并记录种子。历史三轮加速结果属于对应运行，跨设备复测必须单列。它不能作为模型推理加速证据。

`cpu-classifier` 当前第一轮产生正式改善，后两轮无正式改动。页面应显示真实准确率、配置和错例，当前没有大型模型训练损失序列。

`video-cut` 当前允许修改句子选择和顺序，FFmpeg 渲染真实视频，评委主要评价剪后文字。它尚不能证明自动优化了画面美术、运动或音频质量。

仓库源码与来源说明均把 `autoresearch` 列为循环参考；没有导入上游训练引擎。2026-10-25 通过 GitHub 连接读取的 [上游 README](https://github.com/karpathy/autoresearch/blob/master/README.md)仍以单 GPU、小型模型、固定训练预算、修改与保留循环描述产品。上游文件版本为 `953ea55d5599c45c1be7dad93ec03e47dfa7df9d`。上游能力不能计入本项目已完成项。

## 传播与采用的可核查材料

### autoresearch

上游 README 把使用方式讲成具体场景：交给助手一个小型训练任务，持续试验，查看日志和保留结果；开头直接使用进度图。公开 [Hacker News 讨论](https://news.ycombinator.com/item?id=47291123)能证明它引发了有关自动实验、验证和能力边界的讨论，无法单凭该页面拆分作者影响力、代码质量和宣传形式各自的贡献。

对 Open RSI 的判断是：每个主案例也应有一句能复述的任务、一项可检查的变化和直接查看过程的入口。仅说覆盖许多领域，难以让访客判断与自己有什么关系。这是待用户试用验证的产品判断。

### Manus

[官方功能文档](https://manus.im/docs/features/wide-research)把具体任务和输出旁边放置运行回放；[官方线下活动](https://events.manus.im/events/manus-fellow-sf-002)也使用可分享项目作为展示材料。这说明回放与具体案例是其产品传播形式的一部分，没有提供足以证明回放直接带来多少增长的数据。

对 Open RSI 可以采用的办法是，为实际运行生成可直接打开的页面，链接定位到某轮和比较对象。首次打开即可查看作品；愿意尝试的人再进入同款任务。

### Langfuse

[2026-03-24 的官方实践记录](https://langfuse.com/blog/2026-03-24-optimizing-ai-skill-with-autoresearch)说明作者试过自动改进自己的技能，也记录评价目标不充分时产生的副作用。技术用户需要看到任务范围、检查方式和失败原因。

对本项目的意义是把一次有理由的拒绝、未提升或失败保留在可访问的过程里，使结果便于审查。这不要求首页堆满限制文字，具体条件可随案例展开。

## 视频制作路径

[Remotion 的编程助手工作流](https://www.remotion.dev/docs/ai/coding-agents)与[官方技能](https://www.remotion.dev/docs/ai/skills)支持由助手创建动画代码、预览并渲染视频。它可以用于本项目宣传片与演示素材，不依赖新增文生视频模型。具体型号、费用、许可和部署方式在选用时单独核对，本轮没有安装或调用。

首页宣传片应与领域正式实验分开保存。未来让 RSI 修改动画代码，需要另建可改范围、渲染步骤与评价，而不是把宣传片制作记录当作已完成的多轮优化。

## 性能与操作体验参考

[MDN 视频文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video)说明封面、预加载与播放控制；[减少运动设置](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)支持根据用户偏好降低非必要动效。

本项目的具体选择是：首屏先给可读内容和可用入口；视频先给封面，完整媒体按需加载；浏览回放不发起模型任务；运行页在后台任务存在时可刷新与返回。性能目标须通过真实设备测试确认。
