# 02 · RSI 的三个层级 / Three Levels of RSI

> **English summary:** RSI can improve (L1) the current artifact, (L2) durable
> memory used across attempts, and (L3) the harness—prompts, tools, and
> evaluation workflow. Each higher level has more leverage and more risk, so
> promotion requires broader holdout evidence and stricter review.

RSI 不是一个“开或关”的按钮。它有三层递进能力：先改答案，再改经验，最后改
生产答案的系统。越往上，复利越强，作弊和系统性回归的风险也越大。

## L1：产物进化 / Artifact RSI

**改什么：** 当前代码、报告、策略、讲义或设计稿。  
**例子：** 修改一次 SQL 查询后跑同一套性能与回归测试；补充一手数据后按
同一量表重审报告。

```text
candidate v1 → judge → keep/revert → candidate v2
```

L1 最容易验证和回滚，适合作为起点。它的局限是经验常停留在当前任务，下次
可能重踩同一个坑。

## L2：记忆进化 / Memory RSI

**改什么：** `.rsi/lessons.md`、错误分类、检索词库、决策记录和动态 playbook。  
**价值：** 把“这次为什么成功/失败”压缩成下次可执行的规则。

一条好记忆必须包含情境、动作、证据和适用边界：

```text
当财务数据跨币种比较时，先统一汇率日期和会计期间；
否则增长率不可比。本轮审计在表 3 发现 12pp 偏差。
```

不要把未经验证的猜想写成永久规则。定期合并重复项、删除过时规则，并在新
任务上验证迁移效果。记忆也可能造成路径依赖。

## L3：基因进化 / Harness & Skill RSI

**改什么：** Agent 提示词、工具、技能、任务路由、检索流程，甚至候选生成
与审查机制本身。  
**例子：** 多轮实验发现“先做反例检索”稳定提高事实覆盖，于是将它提炼为
可复用 Skill。

L3 改的是“产生下一轮候选的机器”，因此收益能跨任务复利；但它也可能让
整个系统更擅长讨好评测，而不是真正提高能力。

## 晋级规则

| 从 | 到 | 最低证据 |
|---|---|---|
| L1 | L2 | 多轮重复出现；规则有明确适用边界 |
| L2 | L3 | 多个独立任务有效；holdout 不退步 |
| L3 | 发布 | 安全审查、跨模型 diff audit、可回滚版本 |

无论哪一层，评估器都不能与候选一起随意变化。若确需改量表，应开启新的
实验系列、重新测基线，不能把新尺子的分数与旧分数直接比较。

## 常见误区

1. **把日志当记忆**：原始对话很长，却没有下一轮可执行的规则。
2. **过早升级 L3**：一次成功就重写全局 Skill，导致其它任务退步。
3. **让候选改裁判**：系统“进步”只是评分口径变松。
4. **只看平均分**：忽略安全红线和最差案例。

实践原则：从 L1 开始，以证据晋级；更高层必须配更广的测试面、更严格的
权限边界和更容易触发的回滚。
