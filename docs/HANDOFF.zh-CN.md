# 接手开发

换电脑先看[跨电脑协作](COLLABORATION.zh-CN.md)：当前开发主线为 `rebuild`，其中有克隆命令、两种助手的共用规则、共享记录和本机实验的边界。

先读 [中文 README](../README.zh-CN.md)、[首发任务书](GOAL-FIRST-RELEASE.zh-CN.md)及[执行表](GOAL-PROGRESS.zh-CN.md)。任务书定义当前 15 个领域和 API/GPU 资源例外；执行表与原始实验共同决定下一步。研究文档用于查选型，不覆盖当前范围。

当前结果已经收齐：**13 个领域有完整多轮与独立验证，D07 为服务受限的部分实测，D15 待 GPU 实测。** D05 单篇和写作手册均已验收，D11 合同与 D13 讲义也已验收。先看[领域清单](DEMO-PLAN.zh-CN.md)和[35 秒真实产物短片](../examples/showcase-media/openrsi-demo.mp4)，不必重新启动这些完整实验。

## 恢复本机状态

开始前检查当前分支、未提交文件、正在运行的实验和 `.agents/WORKLOG.md`。保留已有修改，不重置工作区，不因为文档写了某个旧提交就切回旧状态。当前交付以拿到的源码为准，远端和 PyPI 状态需要另查，不能默认已同步。

优先复用可用的隔离 Python 环境。本轮使用 Python 3.11 的 `.venv311`，环境目录本身不交付；换机器按[安装说明](INSTALL.zh-CN.md)创建。执行模型任务前检查个人登录、实际 CLI 位置、显式模型和可用资源，避免继承其他项目的配置。

```bash
git status --short
python -m pytest -q
rsi agents
```

测试是程序回归，不会启动完整领域模型实验。涉及依赖的测试是否跳过应一并检查，不能只报告绿色总数。

## 接下来做什么

正式网站品牌为 DARWIN，入口为 [https://www.riseai.top/darwin/](https://www.riseai.top/darwin/)。主站 HTTPS 下的独立路径已部署，当前可浏览、比较和下载真实实验；部署核查见 `release/darwin-deployment.json`。

品牌首页、三个领域页面、全部实验和使用说明已实现，并提供中英文两版（英文为默认，中文在 `/zh/`），见 [网站说明](../web/README.md)与 [产品方案](PRODUCT.zh-CN.md)。运行 `python scripts/build_site.py` 生成 `build/site/`。页面支持真实轮次比较、媒体播放、筛选、分享链接与下载。公开说明文档（安装、扩展、来源、架构，模板、案例与探测说明）均有英文版，英文页自动打开英文版。2026-10-27 改版后完整回归 127 项通过、1 项因缺可选训练依赖跳过；检查记录见 `release/site-validation.json`。改版位于 `claude/darwin-redesign`，尚未部署。下一步优先更换个人获准主案例素材并做试用；网页启动新实验的服务仍待推进。

D01–D06、D08–D14 已有完整结果，保留现有记录、独立验证与展示入口，不为得到更漂亮曲线覆盖实验。D05 手册在三份开发简报上保留 74.5 分版本，用于新读书会简报时从 69 到 77.5；D11 最终覆盖 7/7 类问题；D13 最终十题有依据且答对，结果边界见各案例说明。

D07 保存了初始和第 1 轮真实生成视频；后两轮及一次匿名短描述诊断均返回 `error/null`，没有确认具体服务原因。[派生核验](../examples/video-generation/runs/20261024-003656-warm-morning-product-video/outcome-audit.json) 将后两轮解释为质量未知，原始账本没有修改。按资源例外保留部分实测；服务恢复或有另行获准的免费兼容资源后再开新实验，不自动重试、换账号或付费。

D15 已确认缺个人 GPU，按资源例外交付模板、探测凭证和待补实测说明。没有硬件就保留空分数，不租设备、不使用其他工作的资源。取得合适个人设备后再按 GPU 模板做数值验证、真实多轮与小型推理模块对照。

最终 wheel 已构建并在全新环境离线安装通过，16 个模板的文件与源码逐字节一致；初始化、评分、测试代理运行及导出通过，见 [构建验收](../release/build-validation.json)和[安装回执](../release/install-receipt.json)。当前优先从代码修复、写作手册和视频剪辑中选主展示，替换成用户自己的公开或获准输入；D07/D15 等个人资源具备后再补实验。发布、推送、合并或购买资源按当前授权执行。

集合页面和 35 秒短演示已经生成，媒体与独立验证凭证均已保存。展示页此前完成过领域切换、文字差异、日程预览和视频加载的浏览器检查；后续浏览器访问被拒绝，更新后的派生视图只做了生成器单测、JavaScript 语法与链接检查，不能声称已经重新做过 UI 复查。不要换浏览器或端口绕过拒绝。

## 继续一次实验

先查项目的 `.rsi/runs/<运行号>/run.json`，看状态和执行阶段；再核对账本、最后一轮文件和运行进程。已保存的轮次与中断轮次要分开，不能因为报告文件存在就认为结束。

普通用户在 Demo 目录运行 `rsi run --resume <运行号>`。维护者若使用 `scripts/run_demo.py`，恢复时同时提供原 `--project` 和 `--resume`，不要新建一个实验覆盖同名结果。该维护脚本按本仓库匿名提交身份创建独立实验，其他项目用户优先使用通用 `rsi init` 入口。

新实验显式固定助手、评委和任务模型。源码维护入口示例：

```bash
python scripts/run_demo.py code-repair --model gpt-6.1-sol --rounds 3 --minutes 25 --codex-isolated
```

模板有模型评价时加 `--jury`；提示词与讲义加 `--task-model`；写作手册另设 `RSI_WRITER_MODEL`。这些型号仅为本轮用过的例子，账户不支持时应在新实验中换成可用型号。

## 核验而不是美化结果

- 重跑固定评分前复制到独立临时目录，使用原冻结资料；保存验证记录，不覆盖正式分数。
- 区分正式评审快照与助手内部试验输出。`NO_CHANGE` 或失败轮次不能补画成新的正式得分。
- 请求型号与实际返回型号分开。未知费用和型号保持未知，不从工具名猜测。
- 留出评价单列，不与开发分混算；训练与回测的重复调参限制保留。
- 老的文字实验曾受拼接引文匹配影响，具体限制已写入经营分析与资料综述案例；原始评分保留，当前改进的核对逻辑不回写历史。
- 视频生成优先恢复缓存事件，不能用录屏、静帧或以前的片子补成“新生成”。
- 展示页的“已验收”需要独立验证记录。D07/D15 是资源例外，不计实测通过数量；D07 的原始 0 是失败编码，不是质量得分。

## 当前工程限制

本机评分不是强沙箱；留出文件也不是对有 Git 历史访问权的助手绝对隐藏。总时长在轮次之间检查，不是账单硬上限。视频生成抽帧评分不覆盖完整运动和音频，讲义中的学生限制是提示词约束，模型评分也不等于真人偏好或业务效果。

下一轮改动只解决实际阻塞，已有主循环足以支持首版。新增模板和源代码修改应同时补说明与必要回归，详细结论写进项目文件，面向用户的回复保持简短清楚。
