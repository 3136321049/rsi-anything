# Law and medicine starter

Two frozen checklists in one rubric:

- **Contract redline.** Cited statute ids must exist in `statutes.json`. A hostile reader then counts one-sided remedies.
- **PRISMA-style review.** The memo has to show question, eligibility, search, bias, and a limitation. Invented PMIDs fail the ledger.

```bash
python3 eval_case.py
```

`memo.md` is mutable. The rubric, statute ledger, and evaluator are frozen.
