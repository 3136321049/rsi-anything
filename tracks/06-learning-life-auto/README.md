# Learning and life starter

One packet, two rulers:

- **Feynman guide.** A novice agent should be able to restate the idea. Jargon without a plain restatement, an example, and a check question loses points.
- **ATS resume.** One page, a target role, quantified bullets, and overlap with the job description. Fluff adjectives do not count.
